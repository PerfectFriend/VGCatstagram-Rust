## ⚡ 1. Быстрый старт (3 минуты)

### Системные требования:
- **ОС**: Ubuntu / Debian Linux, macOS или Windows 10/11
- **Инструменты**: Rust 1.80+ (для сборки из исходников) или `dpkg` (для `.deb` пакета)

### Вариант А: Запуск из репозитория
```bash
# Клонирование и переход в проект
git clone https://github.com/PerfectFriend/VGCatstagram-Rust.git
cd VGCatstagram-Rust

# Запуск суверенного демона с веб-интерфейсом на порту 3000
cargo run -p vangoghcat-cli -- start --port 3000 --web ../dist
```
Откройте браузер по адресу: **`http://localhost:3000`**

### Вариант Б: Запуск из родительского проекта VanGoghCat
Из корневой директории проекта доступны готовые команды `npm`:
```bash
npm run test:rust      # Запуск всех 53 тестов ядра
npm run start:rust     # Запуск релизного Rust-сервера на порту 3000
npm run package:rust-deb # Сборка готового пакета .deb для Ubuntu
```

## 🛠️ 2. Шпаргалка по командам CLI (`vangoghcat`)

Утилита командной строки `vangoghcat` позволяет полностью управлять узлом без браузера.

### 🚀 Запуск сервиса (`start`)
```bash
# Базовый запуск на стандартном порту 8765
vangoghcat start

# Запуск с указанием порта и директории веб-интерфейса
vangoghcat start --port 8765 --web /path/to/dist

# Запуск с пользовательской директорией хранилища
vangoghcat start --storage ~/.feline-p2p --port 8765
```

### 📊 Живой терминальный монитор (`monitor`)
Открывает интерактивный ASCII/ANSI дашборд с радаром пиров и шкалой квоты 8 ГБ:
```bash
# Непрерывный мониторинг реального времени (обновление каждую секунду)
vangoghcat monitor

# Однократный снимок состояния (для скриптов и отчетов)
vangoghcat monitor --once
```

### 🔑 Управление ключами идентификации (`key`)
```bash
# Генерация новой ключевой пары Ed25519 и CatNodeID
vangoghcat key generate
```
*Пример вывода:*
```
Generated Sovereign Peer Identity:
  CatNodeID:   catnode18VwZJm6Z87H6k2...
  Public Key:  a8b79f2e3c0d...
```

### 🛡️ Криптографическая защита авторства промптов (`zkp`)
Позволяет доказать, что именно вы придумали оригинальный промпт для картины, не раскрывая его до момента публикации!

```bash
# 1. Фиксация промпта перед генерацией:
vangoghcat zkp commit --prompt "Рыжий кот в соломенной шляпе среди подсолнухов" --author "catnode1alice"

# 2. Проверка доказательства (после раскрытия):
vangoghcat zkp verify \
  --prompt "Рыжий кот в соломенной шляпе среди подсолнухов" \
  --salt <ВАША_СОЛЬ_ИЗ_ШАГА_1> \
  --author "catnode1alice" \
  --commitment <ХЕШ_КОММИТМЕНТА>
```

### ⚡ Прогон микробенчмарков (`benchmark`)
Тестирует скорость аппаратного ускорения SHA-256, деревьев Меркла, Double Ratchet и Keccak-256:
```bash
vangoghcat benchmark
```

## 📦 3. Установка в Ubuntu / Debian через `.deb` пакет

### Сборка и установка:
```bash
# 1. Запуск сборщика пакета
./scripts/build-deb.sh

# 2. Установка созданного пакета
sudo dpkg -i dist/vangoghcat-core_2.0.0_amd64.deb
```

### Управление фоновым сервисом Systemd:
Пакет автоматически регистрирует системную службу `vangoghcat.service`:
```bash
# Включить автозагрузку и запустить службу от вашего пользователя
sudo systemctl enable --now vangoghcat@$USER

# Проверка статуса фонового сервиса
systemctl status vangoghcat@$USER

# Просмотр логов демона
journalctl -u vangoghcat@$USER -f
```

## 🌐 4. Сетевое взаимодействие и Круг Поручителей

1. **Zero-Config Обнаружение в локальной сети**:  
   При запуске двух и более узлов в одной Wi-Fi сети они автоматически находят друг друга через UDP-маяки на порту `8769` без необходимости ручной настройки IP.
2. **Квота хранения 8 ГБ**:  
   - Каждому узлу выделяется **1.6 ГБ** для хранения собственных полотен.
   - Оставшиеся **6.4 ГБ** резервируются для взаимного дублирования картин 4 проверенных поручителей (по 1.6 ГБ на пира).
   - Если один из узлов отключится от сети, его полотна останутся доступными благодаря копиям у 4 поручителей!

## ❓ 5. Часто задаваемые вопросы (FAQ) и диагностика

### Порт 8765 или 3000 уже занят другим процессом:
Укажите любой свободный порт при старте:
```bash
vangoghcat start --port 9090
```

### Где физически хранятся мои полотна и база данных?
По умолчанию все данные хранятся в домашней папке пользователя:
- База метаданных: `~/.feline-p2p/vgc_sled_db/`
- Файлы полотен: `~/.feline-p2p/artworks/`

### Как убедиться, что REST API отвечает?
Выполните простой HTTP-запрос:
```bash
curl http://localhost:8765/health
# Ответ: {"service":"vangoghcat-server-rust","status":"ok"}
```
Проверка статуса пиров и квоты:
```bash
curl http://localhost:8765/api/catp2p/status
```
